# Brightloop frontend (React + Vite + Tailwind)

```bash
cd frontend
npm install
cp .env.example .env     # Windows: copy .env.example .env
npm run dev              # http://localhost:5173  (backend must be running on :8000)
```
Roles: admin/staff -> Dashboard, Subscriptions, Invoices, Payments (admin also Catalog & Admin). Customers -> portal.
Demo logins (password Admin@12345): admin@brightloop.com, staff@brightloop.com, customer@shop.com
